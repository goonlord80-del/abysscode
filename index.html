🔐 Encryption, not just obfuscation

Uses AES-256-GCM. The custom alphabet changes the representation; encryption protects the contents. Keep your key private.

🧩 Compatible with Python

Key-based ABYSSCODE messages use the same container format as the Python CLI. Passphrase mode is not supported in this browser version.

ABYSSCODE is a custom format built on established cryptography, not a new cryptographic algorithm.
