ABYSSCODE.

A custom text-compatible encoding format paired with authenticated encryption. Encode files into an unfamiliar alphabet, then decode them with your key or passphrase.

Download Python script Setup instructions

Quick start

Install Python, then install the dependency:

py -m pip install cryptography

Generate a key and encrypt a file:

py abysscode.py keygen --out abyss.key
py abysscode.py encode secret.txt secret.aby --key-file abyss.key

Decrypt it later:

py abysscode.py decode secret.aby recovered.txt --key-file abyss.key

If you downloaded the script into a different folder, use its path in the commands above.

Security, clearly stated

The custom alphabet is not encryption. AES-256-GCM protects the content and detects tampering; the key or passphrase is what must remain secret. Keep a secure backup of it.

This is a small personal project, not a formally audited security product. The website only distributes the Python script; the script runs locally on your computer.
